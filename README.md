# Hotel Database Management System

## Overview
This project is a MySQL-based Hotel Database Management System designed to manage information about Walt Disney World hotels,
their room types, amenities, and guest reviews. It is tailored to store and query data for various resorts, including details 
such as cost per night, target demographics, and available amenities. The database includes scripts to create tables,
populate them with sample data, and run queries.

## Features
- Hotel Information: Stores details about hotels, including name, rank (Value, Moderate, Deluxe), cost per night,
  target demographic, and best time to stay.
- Room Types: Manages different room types per hotel with maximum occupancy and pricing.
- Amenities: Tracks amenities available at each hotel, such as swimming pools, transportation options, and restaurants.
- Reviews: Stores guest reviews with ratings, comments, and dates.
- Queries: Provides sample SQL queries to retrieve and analyze data, such as hotel amenities, average ratings,
  and room suitability.
